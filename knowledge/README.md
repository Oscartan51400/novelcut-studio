# NovelCut 短剧镜头知识库

这个目录保存 NovelCut 在“导入分镜 → 检查 → 编译 Seedance 提示词”链路中使用的机器可读规则。它不是提示词堆砌，也不会覆盖用户原始分镜。

## 当前作用

- 识别景别、机位角度、主运镜、构图、焦点、镜头焦段、人物调度、转场、光线和常见短剧节拍。
- 在导入预览和工作台提示缺场景、运镜冲突、动作过载、多人物缺站位、入画方向缺失、服装描述不足和可读文字风险等问题。
- 生成前自动补齐主体/场景连续性、默认机位、三段式时间执行、人物站位和少量针对性约束。
- 把身份基准、逐场服装、空间基准、逐镜视角、道具、首尾帧和风格参考拆成单一职责，避免参考图互相污染。
- 按人物身份、服装、道具状态、场景地理、光向、轴线、入出画方向和动作终点八个维度检查跨镜连续性。
- 根据镜头内容智能选择通用镜头配方，并在生成提示词中加入执行骨架、参考资产优先级和连续性复核项。目前覆盖建立、对白、反应、喜剧、灾难、入场、道具变化、动作、救援、情感证明、讽刺、收尾、悬疑、爱情、关系冲突、追逐、打斗、恐怖、情绪崩溃和时间蒙太奇。
- 每条规则可追溯到官方文档或许可明确的 GitHub 项目。

## 数据原则

1. 官方 Seedance 文档优先；其他模型的官方指南只用于验证通用电影语言。
2. GitHub 内容只选许可证明确的项目，且以抽象规则为主，不复制整段提示词案例。
3. 社区经验不当作模型硬能力；冲突时以当前接入 API 的实测结果为准。
4. 原始分镜永远保留，知识库只在生成时形成一个可追溯的编译提示词。
5. 人物基础图只锁定身份和一套默认服装；逐镜服装覆盖基础图外层服装，未换装时继承上一出场状态。
6. 具体项目只作为回归测试集，不把角色、世界观、台词或单部故事偏好写入通用知识库。

## 更新

主文件是 `prompt-knowledge.json`。更新时需要：

- 提升 `meta.version`；
- 在 `sources` 中登记来源、许可证与用途；
- 为新增规则补测试；
- 不加入未经验证的分辨率、时长或接口参数结论。

完整来源清单及各自用途见 JSON 的 `sources` 字段。
