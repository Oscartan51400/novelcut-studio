# NovelCut Studio Alpha

面向个人创作者的 AI 短剧生产工作台。当前 Alpha 已覆盖：

- 先导入并解析分镜，再生成/上传人物定妆和场景基准图，确认后才进入镜头生成；
- 批量上传、拖拽本地 Markdown/TXT，或读取本机文件夹/绝对路径；
- 导入前预览镜头、人物、场景与时长调整，支持替换或追加；
- 角色表、场景表、逐镜人物和关键道具会共同生成完整资产清单，不设资产数量上限；
- 每个镜头按实际需要建立人物造型视角和场景机位资产，基础图锁定身份/空间，逐镜视觉图通过 Seedream 图生图继承基础一致性；
- 人物身份基准与逐镜服装状态分离：基础图只使用一套默认服装，逐镜图按换装覆盖外层服装，未换装时继承人物上一出场状态，并对易漂移颜色补充正向色值与禁色；
- 资产页支持一键顺序生成全部缺失参考图；已有图片不会覆盖，单项失败不阻断其余任务，再次点击只重试仍缺失项；
- 资产页按人物基准、空间基准、道具基准、人物逐镜视觉和场景逐镜视觉分类折叠，并支持全部展开/收起；
- 自动拆成场次和镜头；
- 单屏分镜工作台；
- 项目列表支持删除确认与即时撤销；
- 镜头标题、时长、提示词自动保存；
- Seedance 2.0 单镜生成；
- 每个镜头自动绑定已批准的人物/场景参考图；未锁定关键资产时前后端都会阻止默认生成；
- 镜头与资产使用稳定 ID 关联，支持资产别名、语境修饰词识别、逐镜手动校正和一键恢复自动识别；同一物理空间的机位、区域、昼夜或状态变化默认归入一个基础场景资产，避免重复做场景图和跨镜漂移；
- 720p 快速抽卡、主选镜头一键重新生成 1080p 定稿候选；
- 后台自动查询、下载并保存视频；
- 每镜多候选、质量通过和主选；
- 实时粗剪条；
- FFmpeg 顺序合片；
- 支持导入包含配音、BGM、音效、调色与特效清单的复合制作包，并在每镜检查器中显示对应后期要求；
- 剪辑时长与 Seedance 生成时长分开管理，字幕卡等 `postOnly` 镜头由本机制作，不调用 Seedance。
- 内置可追溯镜头知识库，当前覆盖 14 个官方/GitHub 来源、61 个镜头术语、20 类通用镜头配方、8 个连续性维度、7 类参考图职责和 8 类失败修复规则；生成时会智能加入模板执行骨架、参考资产优先级和连续性复核项。

## 运行

```bash
cd projects/novelcut-studio
cp .env.example .env
npm run dev
```

打开：

```text
http://127.0.0.1:5188
```

macOS 也可以直接双击：

```text
启动 NovelCut Studio.command
```

如果当前工作区的 `zaojing-ai-canvas/.env` 已配置 Seedance Key，开发版会在本项目没有配置 Key 时读取该文件，方便迁移。正式使用建议把 Key 配置到本项目 `.env`。

创建项目或追加分镜时支持三种导入方式：直接粘贴文本、批量选择/拖入 `.md`、`.markdown`、`.mdown`、`.txt` 文件，或读取本机文件/文件夹绝对路径。可以明确选择替换或追加编辑区内容；提交前会预览镜头、人物、场景、时长归一和格式警告。文件夹最多递归扫描 4 层、80 个文本文件，单次总计上限 6MB。项目会保留来源记录，但不会在本机源文件变化时自动覆盖已编辑内容。

实际制作顺序固定为：`1. 分镜解析 → 2. 基础资产与逐镜视觉资产准备 → 3. 人工确认 → 4. 镜头生成与抽卡 → 5. 粗剪与导出`。人物、场景和关键道具图统一调用当前 Seedance 方舟密钥可访问的 Seedream 生图模型，也可上传现有参考图。资产页的“一键生成全部缺失”先生成基础身份/空间图，再以基础图做图生图生成逐镜角度、服装状态、机位和光线参考，不覆盖用户已有版本；批量生成结束后仍需逐项点击“确认使用”，才会进入视频生成。工作台仍保留显式的“纯文本试片”开关供快速试错，但默认关闭且会明确标识一致性风险。

分镜在创建时会把出场人物、场景和已建道具解析为 `assetId`。后续改名时 ID 不变，旧名会成为别名。工作台的“调整本镜关联”可手动多选人物、单选场景和多选道具；手动结果不会被后续文字编辑覆盖。提交生成时固定按“人物 → 场景 → 道具”排序参考图，并在任务中冻结资产版本、锁定设定、参考图路径和当时的逐镜关联快照。

复合制作包可在同一 Markdown 中按章节提供角色、场景、道具与特效、完整镜头提示词、配音脚本及后期合成表。导入预览会把人物/场景身份基准与逐镜视觉资产分开统计，并校验文档声明的镜头总数；数量不一致时会阻止创建，避免静默漏镜。普通镜头的“生成时长”用于 Seedance，“剪辑时长”用于时间线、粗剪和最终合片，两者可以不同。

标有“不需 Seedance”“直接后期制作”或“字幕卡”的镜头会作为后期镜头导入。工作台不会显示 Seedance 生成操作，而是提供本地字幕卡制作。服务优先使用 FFmpeg `drawtext`；当前 FFmpeg 不含该滤镜时，macOS 会通过 `scripts/render-title-card.swift` 渲染中文画面，再由 FFmpeg 编码视频和静音 AAC。该流程不会使用图片或视频生成额度。

## 数据目录

```text
data/novelcut.db       SQLite 元数据
outputs/{projectId}/   Seedance 视频与合片结果
```

## 验证

```bash
npm run verify
npm run test:consistency  # 服务运行时，测试删除后的跨页面与接口一致性
npm run test:assets       # 服务运行时，测试资产前置、批准和镜头绑定
npm run test:source       # 服务运行时，测试角色表、场景表、关键道具和导入预览
npm run test:composite    # 服务运行时，测试复合制作包与后期镜头
npm run test:knowledge    # 测试镜头术语、连续性、调度与服装风险规则
```

后续 Codex 会话先阅读 `AGENTS.md` 和 `docs/CODEX_HANDOFF.md`，其中记录了项目约束、验收样例、预期解析结果与续开发检查清单。

## Alpha 边界

- 当前解析器优先识别 Markdown 分镜标题、表格和带“镜头/分镜”编号的内容；普通长文本会按段落生成草稿镜头。
- Markdown 中的相对图片引用会在导入预览中提示，目前只保留路径，不会自动成为人物或场景参考图。
- 人物/场景参考图已支持本地上传和图片模型生成；当图片模型未配置时，继续使用上传方式。
- 粗剪使用每镜主选候选；没有主选时使用最新成功候选。
- 1080p 定稿采用重新生成，不是无损放大；系统保留原主选，完成后由创作者对比并手动切换。
- 未配置 Seedance Key 时仍可创建和编辑项目，但不能提交真实视频任务。
- 删除项目会先从项目列表隐藏并保留本地素材，便于即时撤销；有生成任务进行中的项目不能删除。
